# PaginaReflex

# Beauty Studio 

Aplicación web desarrollada con Reflex y Python.



# Descripción del proyecto

Este proyecto consiste en una página web interactiva sobre maquillaje y belleza creada utilizando el framework Reflex.

La aplicación incluye:

- Título principal
- Texto de bienvenida
- Botones interactivos
- Cambio dinámico de mensajes
- Diseño personalizado


# Tecnologías utilizadas

- Python
- Reflex
- Poetry
- Git
- GitHub


# Requisitos necesarios

Antes de ejecutar el proyecto es necesario tener instalado:

- Python 3.12 o superior
- Poetry
- Git



# Instalación y ejecución paso a paso

## Clonar el repositorio

Abrir CMD o la terminal y ejecutar:

```bash
git clone https://github.com/brithany01/PaginaReflex.git
```



## Entrar a la carpeta del proyecto

```bash
cd PaginaReflex
```



## Instalar las dependencias del proyecto

```bash
poetry install
```

Este comando instalará automáticamente todas las librerías necesarias para ejecutar la aplicación.


## Activar el entorno virtual

```bash
poetry shell
```

---

## Ejecutar la aplicación web

```bash
poetry run reflex run
```

# Abrir la aplicación en el navegador

Después de ejecutar el proyecto, abrir el navegador y acceder a la siguiente dirección:

```bash
http://localhost:3000
```
